## Projects

### Agentic AI Content Automation Platform
Multi-agent pipeline with autonomous feedback loop: scraper agent, generation agent (LinkedIn and Instagram copy via GPT), and a feedback guardrail agent that reviews and approves content before n8n triggers cross-platform publishing. Runs continuously with no human in the loop.

`Python` `FastAPI` `OpenAI` `Claude API` `n8n` `AWS S3` `LinkedIN API` `Facebook Graph API`

---

### LPO Extraction Dashboard
Client-facing full-stack dashboard using Amazon Bedrock Nova 2 Lite as a multimodal agent to read image and text content from PDF purchase orders. Prompt-engineered a chain of system and follow-up prompts for accurate structured data extraction. JWT auth, rate limiting, auth logging in production.

`Next.js` `FastAPI` `PostgreSQL` `Amazon Bedrock Nova 2 Lite` `OpenAI gpt-5-mini` `Claude Haiku 4.5` `Docker`

---

### Stock Predictor
Browser-based stock prediction platform tracking 60+ stocks. Ingests daily market data, engineers technical features, and runs Random Forest, XGBoost, and Logistic Regression models with SHAP explainability on a live dashboard.

`Next.js` `React` `TypeScript` `Python` `FastAPI` `DuckDB`

---

### Code Review Assistant
Full-stack app that uses a local LLM (Qwen3-4b-thinking) to review code in real time, an implementation of the AI-reviews-AI workflow. Next.js frontend, FastAPI backend.

`Next.js` `FastAPI` `Python` `LM Studio` `Qwen3`

### Natural Language Data Visualizer
Streamlit app that lets users interact with datasets via natural language. Auto-preprocesses data and generates visualizations without writing code.

`Python` `Streamlit` `LM Studio` `CodeLlama`
