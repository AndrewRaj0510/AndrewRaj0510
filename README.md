### Agentic Content Automation
Autonomous multi-agent pipeline: a scraper agent ingests and LLM-scores 50+ RSS and news feeds daily, a content generation agent writes brand-specific LinkedIn and Instagram captions and image prompts, and a feedback guardrail agent approves output before webhook-triggered n8n workflows publish cross-platform. ### ClaimLens: Multimodal Insurance Claims Copilot
Takes a car insurance claim from photo upload to an adjuster-ready recommendation in about 12 seconds (median of 8 claims) at about $0.0014 in LLM cost per claim. A fine-tuned YOLO11 segmentation model detects 6 types of car damage at 0.766 mask mAP@0.5 on 374 held-out images, then a LangGraph agent checks the policy, prices the repair, and looks for fraud signals through MCP tools. Only a human adjuster can approve a claim. Deployed as 12 services on a local Kubernetes (kind) cluster and load-tested at 600 API requests per second with a p95 latency of 29 ms, with CI evaluation gates covering detection, cost error, LLM output quality, and prompt-injection defence.

`Python` `TypeScript` `LangGraph` `MCP` `FastAPI` `Next.js` `YOLO11` `ONNX Runtime` `pgvector` `Redis Streams` `Langfuse` `Kubernetes`

[GitHub](https://github.com/AndrewRaj0510/ClaimLens)

### YieldLens: Property Investment Intelligence Platform
MSc dissertation project that scores a pasted Dubai property listing URL and returns a benchmarked rental-yield verdict with a confidence grade. Integrates 117,443 Dubai Land Department sales and 250,826 Ejari rental contracts through a 7-stage SQL pipeline. Tuned XGBoost was selected over Random Forest and LightGBM via 5-fold cross-validation, reaching a held-out R-squared of 0.872 against 0.343 for a baseline, with per-request SHAP explanations and a grounded GPT-5 narrative and Q&A layer.

`Python` `SQL` `Supabase` `XGBoost` `LightGBM` `SHAP` `FastAPI` `Next.js` `OpenAI GPT-5`

[GitHub](https://github.com/AndrewRaj0510/Property_Investment_Intelligence)

### WikiGuard: Live Wikipedia Vandalism Detector
In progress. A production-style MLOps system that reads live Wikipedia edits from Wikimedia's event stream, scores each one for vandalism risk with deep learning models, and ranks the riskiest edits for human reviewers, with a one-line LLM explanation. A person always makes the final call. The design compares five neural networks on the same data, uses community reverts as delayed labels to measure live accuracy, and retrains on drift behind a strict promotion gate. The data pipeline is being built now; there are no model results yet.

`Python` `FastAPI` `Next.js` `PostgreSQL` `Redpanda` `Docker`

[GitHub](https://github.com/AndrewRaj0510/WikiGuard)
